# Repository guidance

This repository and its pull requests are public. Never include specific business details from real work in files, examples, commit messages, pull request descriptions, or comments. This includes company and product names, internal repository names, ticket identifiers, hostnames, URLs, and links to real project work, even when a link is publicly accessible.

When real work suggests an improvement here, describe the reusable lesson with fictional examples and example URLs. Review the exact diff and pull request text for identifying details before publishing.
